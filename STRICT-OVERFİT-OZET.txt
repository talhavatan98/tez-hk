4. TECHNICAL ARCHITECTURE OF OVERFITTING CONTROLS
================================================================================

The project employs a 3-Layer Defense System against overfitting:

LAYER 1: INTERNAL METHOD CONTROLS (Inside Analysis Scripts)
--------------------------------------------------------------------------------
- Stratified Split: Data split 70/30 BEFORE any processing to prevent leakage.
- Cross-Validation: 10-Fold CV repeated 5 times for robust tuning.
- Feature Selection: Conservative pre-filtering (Top 200) to reduce noise.
- Permutation Tests: 200-1000 iterations to validate statistical significance.

LAYER 2: STRICT CHECK SCRIPTS (Post-Hoc Validation)
--------------------------------------------------------------------------------
Scripts: STRICT_OVERFITTING_CHECK_*.R
- Function: Re-loads saved models and manually recalculates predictions.
- Logic: Compares Train vs Test metrics to calculate "Generalization Gap".
- Scoring: Assigns a 1-5 Star rating based on gap size and consistency.

LAYER 3: MASTER SUMMARY (Comparative Synthesis)
--------------------------------------------------------------------------------
Script: MASTER_OVERFITTING_SUMMARY.R
- Function: Aggregates results from all methods.
- Output: Generates comparative plots (PDF) and unified tables (CSV).
- Purpose: Provides the "Big Picture" for publication and ranking.
